# Оценить расход пряжи

Откройте схему вязания и включите **Расход пряжи** в настройках отображения.
Рядом со схемой появится панель с расчётом для текущей детали.

Расход показан отдельно для каждой пряжи: число петель, примерная длина нити и
вес в граммах, если для пряжи указан метраж. Это черновая оценка; для сложных
узоров и жаккарда реальный расход может быть больше.

В расчёт попадает только пряжа, которой действительно провязаны петли в этой
схеме. Поэтому пряжа из списка проекта, которая пока нигде не используется, не
появится в расходе и не повлияет на результат. Можно спокойно добавлять пряжу
в список заранее — она начнёт учитываться, только когда вы назначите её
петлям.

Если пряжа, которую вы ожидали увидеть в расчёте, не показывается, значит в
текущей схеме нет ни одной петли, провязанной этой пряжей. Проверьте, не
пропустили ли вы нужное действие — например, заливку области этой пряжей.
