# Смотреть порядные текстовые инструкции

Включите [режим вязания](../concepts/knitting-mode.md) и нажмите кнопку
**Текстовые инструкции** с иконкой листа в панели счётчика рядов.

Панель показывает инструкцию для текущего ряда. После переключения счётчика
она автоматически переходит к следующему ряду. В инструкции указаны действия
с петлями и число петель в работе; при необходимости также видны направление,
сторона вязания, участки узора и смена пряжи.

Если ряд состоит из нескольких частей при частичном вязании, вверху панели
можно выбрать инструкцию для всего ряда или для отдельной части.

Текстовые инструкции всегда автоматически строятся по текущему состоянию
схемы. Они не проверяют её размер, корректность или ожидаемый результат:
сначала подготовьте и проверьте схему, затем используйте инструкцию как
текстовую запись того, что в ней сейчас нарисовано.
