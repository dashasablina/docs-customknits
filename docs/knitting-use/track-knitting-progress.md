# Вязать с отображением прогресса

Включите [режим вязания](../concepts/knitting-mode.md). Счётчик начнёт с нуля,
а на схеме будет выделен первый ряд.

После того как свяжете ряд, нажмите **▲** в счётчике или клавишу **↑**. Схема
перейдёт к следующему ряду, а провязанный ряд останется отмеченным как
выполненный. Клавиша **↓** возвращает на предыдущий ряд. На компьютере также
работают клавиши Page Up и Page Down.

Если нужно исправить отметку, нажмите на число в счётчике и введите нужный
номер ряда. Кнопка **Сбросить счётчик** возвращает прогресс к началу схемы.

Счётчик ведётся отдельно для каждой схемы вязания. При переключении между
схемами вы увидите её собственный текущий ряд.

## Настроить подсветку прогресса

В режиме вязания нажмите кнопку с шестерёнкой в панели счётчика. В её
настройках можно включить подсветку текущего и уже провязанных рядов, а также
выбрать их цвета. Для активного ряда есть два способа чередовать цвета:

- через заданное количество петель;
- при смене пряжи.

Во втором варианте число петель каждого цветного участка CustomKnits считает
автоматически. Он особенно удобен для вязания цветных узоров: не нужно вручную
считать, сколько петель провязать каждой пряжей.

Перед рядом или в текущем ряду CustomKnits может предупредить об изменении
числа петель или пряжи. Это подсказка свериться со схемой перед продолжением.
