# Поделиться проектом

1. Откройте **Главное меню** в шапке редактора.
2. Выберите **Поделиться проектом**.
3. Отправьте созданную ссылку человеку, которому хотите передать текущую копию
   проекта, или себе на другое устройство.

<img
  src={require('/img/work-with-project/project-menu.png').default}
  srcSet={require('/img/work-with-project/project-menu.png').default + " 2x"}
  alt="Главное меню с командой Поделиться проектом"
/>

На компьютере ссылка копируется в буфер обмена. На телефоне откроется окно, где
ссылку можно скопировать или отправить через системное меню.

По ссылке открывается копия проекта на момент создания ссылки. Это удобно,
когда нужно передать проект целиком другому человеку для редактирования или
продолжить работу на другом устройстве — например, открыть проект на телефоне,
куда не всегда удобно отправлять файл.

Это не совместное редактирование: дальнейшие изменения вашего проекта не
появятся у получателя, а его изменения не появятся у вас.

Перед открытием общего проекта CustomKnits предложит сохранить текущий проект
на компьютере или отправить себе ссылку на него на телефоне. Открытый по ссылке
проект можно продолжать редактировать как отдельную копию.

Отправляйте ссылку только тому, кому готовы показать всё содержимое проекта.
Если хотите показать только результат или его часть, используйте подходящий
экспорт: отдельно выкройку, схему вязания, список узоров или коллаж с
предпросмотром проекта.

<img
  src={require('/img/work-with-project/project-menu-export-options.png').default}
  srcSet={require('/img/work-with-project/project-menu-export-options.png').default + " 2x"}
  alt="Раздел Экспорт в главном меню с выкройкой, вязанием, узорами и пряжей"
/>

Ссылка не предназначена для хранения проекта. При её создании файл проекта
временно записывается на сервер CustomKnits, а через несколько дней проекты по
ссылкам, которые не были открыты, автоматически удаляются. Если ссылка больше
не открывается, она могла устареть или стать недействительной.
