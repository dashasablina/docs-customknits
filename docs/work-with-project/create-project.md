# Создать проект

Откройте главное меню и выберите **Новый проект**. Если в редакторе уже есть
работа, сначала [сохраните проект](./save-project.md): создание нового проекта
заменяет текущий.

  src={require('/img/work-with-project/project-menu.png').default}
  srcSet={require('/img/work-with-project/project-menu.png').default + " 2x"}
  alt="Главное меню с командой Новый проект"
/>

В окне выбора можно начать с той части работы, которая уже понятна. Остальное
добавляется в проект позже.

## Выбрать начало работы

- **Открыть пример** — в интерфейсе этот вариант называется **Использовать
  пример**. Он открывает готовый проект с выкройками и расчётами, который можно
  редактировать или использовать как есть.
- **Вещь целиком по шаблону** создаёт набор выкроек выбранного изделия, а затем
  предлагает рассчитать по ним детали вязания.
- **Начать с выкроек** создаёт одну деталь или набор выкроек по шаблону.
- **Начать с вязаных деталей** создаёт образец с заданным размером или
  предлагает рассчитать вязание по уже подготовленной выкройке.
- **Пустой проект** открывает чистый проект, в который вы сами добавите
  выкройки и детали вязания.

На телефоне пока доступны только **Использовать пример** и **Вещь целиком по
шаблону**. Для остальных вариантов начните проект на компьютере, а затем при
необходимости откройте его на телефоне.

Выбор варианта не фиксирует структуру проекта: позже можно добавить новые
выкройки, вязание, пряжу и плотность.
