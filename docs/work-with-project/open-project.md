# Открыть проект

Если в редакторе уже открыт незавершённый проект, сначала [сохраните его](./save-project.md):
открытый файл заменит текущий проект в редакторе.

1. Откройте **Главное меню** в шапке редактора.
2. Выберите **Открыть проект**.
3. Найдите и выберите файл проекта.

<img
  src={require('/img/work-with-project/project-menu.png').default}
  srcSet={require('/img/work-with-project/project-menu.png').default + " 2x"}
  alt="Главное меню с командой Открыть проект"
/>

CustomKnits открывает сохранённые файлы `.cknit`. После открытия с проектом
можно работать как обычно; он остаётся в браузере для быстрого возвращения к
работе, но это не заменяет сохранение отдельного файла.

На компьютере файл `.cknit` также можно перетащить в окно редактора. В этом
случае CustomKnits спросит, открыть его сразу или сначала сохранить текущий
проект.
