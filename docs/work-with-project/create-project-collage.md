# Создать коллаж для проекта

1. Перейдите к любой схеме вязания в проекте.
2. Откройте **Главное меню**.
3. Выберите **Составить коллаж для проекта**.

В коллаж можно добавить схемы вязания из текущего проекта, а также свои
изображения PNG и JPG. Каждый объект становится отдельным слоем: его можно
перемещать, масштабировать, поворачивать, скрывать, блокировать,
переименовывать и менять порядок слоёв. На холсте также можно добавить текст,
рисунок или простую фигуру.

Коллаж подходит не только для общего дизайна, но и для грубой оценки
пропорций изделия. В меню **Добавить детали и картинки** выберите
**Добавить силуэт**. Сейчас доступен женский параметрический силуэт: задайте
рост и обхваты человека, для которого вяжете вещь, — силуэт изменит свои
пропорции. Добавьте на него детали вязания и расположите их на холсте. Так
можно примерно оценить общую длину изделия или длину рукавов.

Это не сборка вещи и не 3D-примерка, поэтому не используйте коллаж для точной
посадки. Он помогает быстро сравнить пропорции и оценить общий дизайн.

Детали вязания, добавленные из проекта, связаны с их источником в редакторе.
После изменения детали они не обновляются сами: в списке слоёв появится
отметка **Нужно обновить**. Нажмите **Обновить слой** для одной детали или
**Обновить все**, чтобы перенести актуальные схемы в коллаж.

Когда композиция готова, откройте меню коллажа и выберите **Экспорт превью**.
Готовое изображение будет сохранено в PNG — его удобно отправить человеку или
показать как результат проекта, не передавая сам редактируемый проект.

Если хотите продолжить работу с коллажем позже или перенести его вместе с
проектом, в меню коллажа выберите **Сохранить сцену в проекте**. К проекту
можно привязать одну редактируемую сцену; она войдёт в сохранённый файл
проекта. Черновик, который не сохранён в проект, остаётся только в браузере.

Если для одного проекта нужно несколько сцен или в коллаже много графики,
сохраните его через **Экспортировать файл сцены** на компьютер. Такой файл
можно затем открыть командой **Открыть файл сцены** в меню коллажа. Файл сцены
откроется только для проекта, с которым был создан: это нужно, чтобы детали
вязания в коллаже оставались связанными с правильными схемами и могли
обновляться.
