# Работать с проектом на телефоне

На телефоне удобно открыть готовый проект, быстро выполнить расчёт, смотреть
схему и пользоваться инструкциями во время вязания. При первом входе
CustomKnits предупредит, что детально настраивать и редактировать проект лучше
на компьютере. Нажмите **Открыть мобильную версию**, чтобы продолжить.

## Перенести проект на телефон

На компьютере откройте **Главное меню → Поделиться проектом** и отправьте
созданную ссылку себе. Откройте её на телефоне и подтвердите открытие проекта.
Если на телефоне уже есть важный текущий проект, CustomKnits предложит сначала
отправить ссылку на него себе.

Ссылка открывает отдельную копию проекта. Подробнее о сроке действия ссылки и
о передаче проекта другому человеку — в статье [Поделиться проектом](./share-project.md).

Держите основную сохранённую копию проекта на компьютере. Проект, который
виден в браузере телефона, нужен для быстрого возвращения к работе и не
заменяет файл `.cknit`.
