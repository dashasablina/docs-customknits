# Сохранить проект

Сохранение создаёт отдельный файл с текущим проектом. Его можно хранить как
резервную копию, перенести на другое устройство или позднее снова открыть в
CustomKnits.

1. Откройте **Главное меню** в шапке редактора.
2. Выберите **Сохранить проект**.

<img
  src={require('/img/work-with-project/project-menu.png').default}
  srcSet={require('/img/work-with-project/project-menu.png').default + " 2x"}
  alt="Главное меню с командой Сохранить проект"
/>

На компьютере укажите имя и место для файла, если браузер предложит это
сделать. В зависимости от браузера может открыться системное окно выбора папки
или файл скачается в папку загрузок.

На телефоне вместо выбора папки откроется системное меню **Поделиться**:
выберите приложение или человека, которому хотите передать файл проекта.

Проект сохраняется в файле с расширением `.cknit`.

В файл входит текущее содержимое проекта: выкройки, схемы вязания, пряжа,
плотность и данные самого проекта.

Это не экспорт выкройки, схемы или изображения: файл `.cknit` сохраняет весь
редактируемый проект. Если меняете имя файла, расширение `.cknit` добавится
автоматически.

Важно регулярно сохранять проект на компьютер. CustomKnits не хранит проекты
на своих серверах. Когда при следующем входе в редактор открывается последний
проект, это локальная копия в вашем браузере: она нужна, чтобы быстро вернуться
к работе и отменить недавние действия, но не заменяет сохранённый файл.
