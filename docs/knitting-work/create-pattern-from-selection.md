# Создать узор из выделения

Выделите на схеме петли, из которых хотите сделать повторяемый узор. Откройте
контекстное меню и выберите **Создать узор для заливки из выделенного**.

Фрагмент станет текущим узором. Его можно сразу использовать для заливки другой
области схемы или сохранить в проекте.

Подробности о видах выделения и о том, как редактор переносит свойства петель,
добавим вместе со скриншотами.
