# Выбрать узор в библиотеке

Откройте текущий узор на правой верхней панели доски вязания и перейдите во
вкладку **Библиотека**. Выберите карточку узора, настройте доступные параметры
и используйте результат в проекте.

Узоры библиотеки параметрические: карточка не является неизменяемой картинкой.
После выбора можно менять её параметры, а затем сохранить удачный вариант в
проекте.

Подробный выбор коллекций, параметры карточек и применение узора к схеме
добавим вместе со скриншотами.
