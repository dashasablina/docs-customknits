# Нарисовать узор в редакторе жаккарда

Откройте текущий узор на правой верхней панели доски вязания и перейдите во
вкладку **Редактор жаккарда**. Задайте размер сетки, выберите пряжу и рисуйте
узор по клеткам. Затем нажмите **Использовать узор в проекте**.

Готовый жаккард становится текущим узором: его можно применить к схеме и
сохранить в проекте.

Подробные инструменты рисования, работу с цветами и скриншоты добавим отдельно.
