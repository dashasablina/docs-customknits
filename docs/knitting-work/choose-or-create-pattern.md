# Выбрать или создать узор

Текущий узор показан компактным превью в правой верхней панели доски вязания,
под выбранным типом петли. Нажмите на превью, чтобы открыть окно **Узоры**.
Выбранный узор применяется при заливке и рисовании схемы, а также может стать
начальным узором при расчёте по выкройке.

## Открыть варианты

В окне **Узоры** есть четыре способа начать:

- **Библиотека** — готовые узоры. Все узоры в библиотеке параметрические:
  выберите карточку и настройте доступные для неё параметры.
- **Генератор** — создаёт узор по заданным параметрам.
- **Редактор жаккарда** — нарисуйте цветной узор по клеткам.
- **Конструктор** — соберите узор из доступных элементов.

Выберите или создайте узор, затем используйте его для заливки нужной области
схемы. Если выбранный узор содержит собственные цвета, можно отдельно решить,
использовать ли его пряжу или пряжу текущего проекта.

## Создать узор из части схемы

Выделите нужные петли на доске вязания, откройте контекстное меню и выберите
**Создать узор для заливки из выделенного**. Редактор сделает этот фрагмент
текущим узором. Затем его можно применить к другой области схемы или сохранить
в проекте.

## Сохранить и перенести узоры

Любой текущий узор можно назвать и сохранить в проекте с помощью действия
**Сохранить в проекте**. Сохранённые узоры остаются в проекте и доступны в
библиотеке.

Чтобы перенести их в другой проект, в главном меню откройте **Экспорт →
Узоры → Экспорт сохранённых узоров**. В другом проекте используйте **Импорт →
Узоры → Импорт сохранённых узоров**.
