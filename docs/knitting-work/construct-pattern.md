# Собрать узор в конструкторе

Откройте текущий узор на правой верхней панели доски вязания и перейдите во
вкладку **Конструктор**. Выберите элементы и параметры будущего узора, затем
нажмите **Использовать узор в проекте**.

Собранный результат становится текущим узором. Его можно применить к схеме или
сохранить в проекте для повторного использования.

Подробный сценарий сборки и скриншоты добавим, когда уточним поведение
конструктора.
