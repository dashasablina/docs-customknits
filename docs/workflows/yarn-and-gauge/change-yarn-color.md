# Поменять цвет пряжи

Этот сценарий нужен, если вы хотите быстро попробовать другой цвет для уже существующей пряжи.

## Перед началом

Важно: изменение цвета пряжи меняет все петли этой пряжи во всех деталях проекта. Если нужно поменять цвет только у части схемы, нужно назначить выбранным петлям другую пряжу.

Выбранная пряжа применяется к новым петлям и к петлям, которые вы редактируете. Список пряжи управляет всеми пряжами проекта и их цветами.

## Как поменять цвет

1. Откройте панель свойств.
2. Найдите выбранную пряжу: она обозначена иконкой клубка.
3. Нажмите на цвет выбранной пряжи.
4. Выберите новый цвет.
5. Подтвердите изменение.
