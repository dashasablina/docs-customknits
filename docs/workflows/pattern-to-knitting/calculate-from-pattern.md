# Рассчитать схему вязания по выкройке

Расчет петель по выкройке в редакторе сводится к заполнению формы расчета.

Перед расчетом нужна готовая выкройка и правильно заданная плотность по связанному образцу.

## Открыть форму расчета

Нажмите **Создать по выкройке** в правом верхнем углу.

  src={require('/img/knitting/pattern-to-knitting/create-from-pattern-button.png').default}

  alt="Кнопка Создать по выкройке"
/>

В открывшейся форме заполните параметры и нажмите **Рассчитать**.

<img
  src={require('/img/knitting/pattern-to-knitting/calculate-from-pattern-form.png').default}

  alt="Форма расчета петель по выкройке"
/>

После расчета редактор построит схему вязания по выбранной выкройке. С готовой схемой можно работать дальше: менять петли, пряжу, плотность, узоры и другие свойства.

## Основные параметры

В форме можно выбрать одну или несколько выкроек, которые войдут в расчет.

Ключевой параметр — **плотность**. Перед расчетом обязательно проверьте, что выбрана правильная плотность по связанному образцу. Если плотность задана примерно, схема тоже будет рассчитана примерно.

Также в форме задаются:

- узор;
- пряжа;
- направление вязания: снизу вверх или сверху вниз;
- направление первого ряда;
- способ вязания: по кругу или поворотными рядами;
- поперечное вязание.

Направление вязания определяет порядок нумерации рядов. Направление первого ряда и способ вязания определяют нумерацию петель внутри рядов.

Если включить **Поперечное вязание**, редактор рассчитает петли так, как будто выкройка повернута на 90 градусов.

## Прибавки, убавки и частичное вязание

В форме есть настройки, которые сейчас работают в тестовом режиме:

- автоматически определять частичное вязание;
- автоматически расставлять прибавки и убавки.

Если включена автоматическая расстановка прибавок и убавок, дополнительно задается расстояние от края.

Также можно выбрать, в каких рядах допустимы прибавки и убавки:

- только в четных;
- только в нечетных;
- в любых.

Эти параметры помогают сделать результат удобнее для ручного вязания и для вязания на бытовой вязальной машине. Например, для машины может быть важно начать первый ряд слева направо. Для ручного вязания может быть удобнее, чтобы прибавки и убавки попадали только в лицевые ряды.

## Разные параметры для блоков

Если на выкройке заданы несколько блоков, для каждого блока можно указать свои параметры перевода.

Например, для резинки и основного полотна можно выбрать разные узоры уже на этапе расчета. Или с помощью блоков заранее сделать дизайн: например, колор-блок из разных пряж.

Такой дизайн задается на уровне выкройки и не зависит напрямую от плотности. Это удобно, если один и тот же дизайн нужно перевести в петли с разными плотностями без сложных ручных правок после расчета.
