# Статистика проекта

Эта статья будет описывать статистику проекта: расход пряжи и другие расчетные показатели, которые редактор может показать по текущей схеме.

## Что нужно описать

- Где находится статистика проекта.
- Как считается расход пряжи.
- Что меняется, если у пряжи задан метраж.
- Как расход считается для секционной пряжи.
- Какие ограничения есть у расчета.
- Почему расчет расхода является оценкой, а не гарантией.
