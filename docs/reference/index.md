# Справочник

Справочник будет описывать не пользовательские маршруты, а отдельные части редактора: панели, настройки, инструменты, режимы и форматы.

## Будущие подразделы

- Общий интерфейс.
- Доска выкроек.
- Контур выкройки.
- Внутренние вырезы.
- Внутренние точки и сегменты.
- Блоки выкройки.
- Специфические для вязания действия с линиями выкройки.
- Доска вязания.
- Инструменты редактирования петель.
- Пряжа, плотность, типы петель.
- Сохранение, импорт и экспорт.

## Статус

Раздел пока заготовлен для новой структуры. Старые справочные материалы сохранены в архиве старой структуры.
