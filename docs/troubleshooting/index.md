# Решение проблем

В этом разделе будут короткие статьи формата: симптом, возможная причина, что сделать, как проверить результат.

## Будущие темы

- Проект не открывается.
- Файл не сохраняется.
- Вязание по выкройке получилось не таким, как ожидалось.
- Внутренний вырез или разрез ведет себя не так, как ожидалось.
- Картинка вставилась с неправильными цветами.
- Экспорт или печать выглядят неправильно.
- Приложение тормозит на большом проекте.
