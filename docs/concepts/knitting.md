# Схема вязания

Схема вязания — это представление детали в петлях.

На схеме для каждой петли указано, какой пряжей она связана, какой у нее тип петли и какая плотность используется. Тип петли — это, например, лицевая, изнаночная и другие виды петель.

## Схемы в проекте

В проекте может быть несколько схем вязания. Может не быть ни одной: например, если пользователь пока работает только с выкройками.

Схему можно создать вручную или рассчитать по выкройке. Схема, рассчитанная по выкройке, не становится заблокированной: ее можно редактировать после расчета.

Для схем есть отдельное место редактирования — доска вязания. На доске вязания одновременно открыта одна схема детали.

Со схемами вязания можно:

- создавать схемы;
- копировать;
- редактировать;
- удалять.

## Редактирование схемы

Редактирование схемы — это изменение свойств петель: пряжи, плотности и типа петли.

Такие изменения можно делать по-разному: для одной петли, для выделенной области, для части детали или другими инструментами редактирования. Подробные действия будут описаны в сценариях.
