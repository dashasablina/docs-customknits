# Выкройка

Выкройка в CustomKnits — это форма отдельной детали в сантиметрах: например,
переда, спинки или рукава. По готовой форме можно рассчитать схему вязания,
но выкройка не обязательна: со схемой можно работать и напрямую.

Внешнюю форму задаёт контур из точек и линий. При необходимости внутри детали
можно добавить линии и блоки: они помогают подготовить отдельные области и
правила для будущего расчёта схемы.

## Выкройки в проекте

В проекте может быть несколько выкроек. Может не быть ни одной: например, если пользователь сразу работает со схемой вязания без построения формы в сантиметрах.

Для выкроек есть доска **Выкройки**. В одном проекте может быть несколько
деталей, и все они отображаются на одном холсте. Одна из них выбрана: именно
её точки, линии и настройки редактируются. Чтобы переключиться на другую
выкройку, нажмите на неё на холсте.

Начните с нужного способа создания:

- [Нарисовать и изменить выкройку](../pattern-work/draw-and-edit.md) — если
  форму нужно построить или поправить вручную.
- [Создать выкройку по размерам готового изделия](../pattern-work/from-measurements.md)
  — если нужна готовая конструкция, которую затем можно изменить.
- [Каталог шаблонов выкроек](../pattern-work/templates.md)
