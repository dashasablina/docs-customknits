# Выкройка

Выкройка в CustomKnits — это деталь в сантиметрах. Она описывает форму до перевода в петли и помогает работать с размерами, линиями и областями детали.

Выкройка состоит из контура, внутренних линий и блоков. Контур задает внешнюю форму детали. Внутренние линии можно использовать для разметки, подготовки разрезов и других технических задач. Блоки — это области выкройки, для которых могут быть заданы разные правила перевода в петли.

У выкроек также есть специфические для вязания действия с линиями. Они нужны, когда форма готовится не просто как геометрия в сантиметрах, а как основа для будущей схемы вязания.

## Выкройки в проекте

В проекте может быть несколько выкроек. Может не быть ни одной: например, если пользователь сразу работает со схемой вязания без построения формы в сантиметрах.

Для выкроек есть отдельное место редактирования — доска выкроек. Все выкройки проекта одновременно находятся на этой доске.

  src={require('/img/pattern/pattern-board-overview.png').default}
  srcSet={require('/img/pattern/pattern-board-overview.png').default + " 2x"}
  alt="Доска выкроек с несколькими выкройками проекта"

На доске выкроек можно:

- создавать выкройки;
- двигать их;
- редактировать;
- копировать;
- удалять.

Подробные действия с выкройками будут описаны в сценариях.
